ChupaTuring2000

Toolkit em Python para gerar um caderno de permutações A–Z e cifrar/decifrar letra a letra, uma linha do pad por posição da mensagem.

Este projeto foi vibecoded (conversa com Grok + script). Não é um produto de criptografia. Não esconda nada que doa perder.

O nome

Turing comeu estrutura. Um pad sem estrutura, usado uma vez, não tem gosto. Shannon (1949) que formalizou o “porquê”. O resto é piada e papel.
